# Calculator

A high-performance calculator application built with C++.

## Features

- Fast and efficient computation
- User-friendly interface
- Cross-platform compatibility
- Well-structured C++ codebase

## Requirements

- C++11 or higher
- CMake 3.10+
- A C++ compiler (GCC, Clang, or MSVC)

## Build Instructions

### Prerequisites

Make sure you have the following installed:
- CMake
- A C++ compiler compatible with C++11 or later

### Building the Project

```bash
# Clone the repository
git clone https://github.com/Victor1514-soft/Calculator.git
cd Calculator

# Create a build directory
mkdir build
cd build

# Generate build files
cmake ..

# Build the project
cmake --build .
```

## Usage

```bash
# Run the calculator
./calculator
```
